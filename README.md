## 🌟 为什么开发这个项目？

很多个人投资者希望使用量化规则监控自选基金（如均线分位、相对高低点、加减仓提醒），但面临以下痛点：
1. **服务器负担重**：需要自己租用云服务器、配置 Python 环境、维护数据库与局域网 IP。
2. **隐私担忧**：不希望将自己的真实持仓与自选基金上传到第三方不受控的服务器。
3. **出门不便**：离开电脑或特定局域网 WiFi，就无法实时查看监控。

**本项目彻底颠覆了传统的“客户端 + 服务器”架构**：
将所有的网络行情请求、双策略量化数学计算与数据持久化，**全部移植到手机本地运行**。打开 App 即用，随身携带，零维护成本。

## 🚀 核心功能特性

### 1. 📱 真正的零服务器架构 (Zero-Server)
* **原生网络直连**：基于 Capacitor 原生网络底层，手机直连天天基金与腾讯行情公开接口，**无跨域限制、无中间服务器代理**。
* **极速本地存储**：自选基金与自定义参数直接保存在手机本地 `localStorage`，读写耗时 $<1\text{ms}$，数据永不上传云端，彻底保护财务隐私。
* **免登录秒开**：无需注册账号和输入密码，打开 App 0.1 秒直达监控主页。

### 2. ⚡ “位置定方向，波动定力度” 双层量化决策系统 (Position-Gated, Volatility-Enhanced Model)

在量化投资中，如果在震荡行情中盲目依据单日暴涨暴跌进行交易，极易沦为追涨杀跌。本项目采用**「主次分级自适应决策体系」**，将资金安全与科学纪律置于首位：

* 🎯 **【基准主策略 · 定方向（做不做）】近 90 天区间相对位置标尺**：
  * 回溯近 90 个交易日真实复权净值走势，锁定区间最高点 $NAV_{max}$ 与最低点 $NAV_{min}$；
  * 计算当日实时预估净值在区间内的百分比相对位置：
    $$PosRatio = \frac{NAV_{est} - NAV_{min}}{NAV_{max} - NAV_{min}} \times 100\%$$
  * **战略门槛**：
    * **$PosRatio \le 20\%$**：进入**历史低位区**，取得**买入操作准入资格**；
    * **$PosRatio \ge 80\%$**：进入**历史高位区**，取得**卖出操作准入资格**；
    * **$20\% < PosRatio < 80\%$**：判定为**中位常态震荡区**。此时系统开启**噪音过滤器**，**坚决不操作、继续持有观望**，杜绝无谓摩擦成本！

* ⚡ **【辅助增强因子 · 定力度（做多少）】近 30 天大幅波动分位数**：
  * 本地解析近 30 个交易日历史日收益率，动态计算 **90% 上涨分位阈值（极端超涨）** 与 **10% 下跌分位阈值（极端超跌）**；
  * 该策略**不单独触发开仓**，而是充当**动态仓位调节乘数**：
    * 当标的处于**低位区 ($\le 20\%$)** 时，若当日叠加遭遇**恐慌性暴跌（击穿 10% 分位）**，触发**黄金坑共振**，信号立即升级为 **🔥【强力加仓】**（建议加大定投额度或重仓低吸）；若未暴跌，则维持 **🌱【常规加仓】**；
    * 当标的处于**高位区 ($\ge 80\%$)** 时，若当日叠加遭遇**加速赶顶狂热暴涨（突破 90% 分位）**，触发**赶顶共振**，信号立即升级为 **🚨【强力减仓】**（建议大幅止盈落袋为安）；若未暴涨，则维持 **🍂【常规减仓】**。

#### 📊 量化决策对照矩阵表

| 主策略：90天区间标尺 (定方向) | 辅因子：30天波动分位 (定力度) | 最终决策指令 | 仓位管理指引 |
| :--- | :--- | :--- | :--- |
| **低位区 ($\le 20\%$)** | **触发恐慌超跌 (击穿10%分位)** | 🔥 **【强力加仓】** | 双重共振极佳买点，建议加大买入力度/多倍定投 |
| **低位区 ($\le 20\%$)** | 未触发超跌 (常态/微跌) | 🌱 **【常规加仓】** | 处于估值洼地，按标准定投/网格正常逢低买入 |
| **高位区 ($\ge 80\%$)** | **触发加速超涨 (突破90%分位)** | 🚨 **【强力减仓】** | 双重共振极佳止盈点，建议大比例止盈锁定利润 |
| **高位区 ($\ge 80\%$)** | 未触发超涨 (高位震荡) | 🍂 **【常规减仓】** | 进入风险溢价高位区，建议分批阶梯式减仓 |
| **中位区 ($20\% \sim 80\%$)** | 无论日内涨跌多剧烈 | ☕ **【持有观望】** | **自动滤除单日波动噪音**，避免在震荡市追涨杀跌 |

### 3. 📋 全组合一键汇总报告（全面升级可视化）
* **四档操作智能置顶排序**：体检完成后，标的按紧迫程度全自动升序排列：  
  **🔥 强力加仓 > 🌱 常规加仓 > 🚨 强力减仓 > 🍂 常规减仓 > ☕ 观望持有**。需要重点操作的基金优先排在最顶部，配以发光边框与动态标签，一秒锁定核心标的。
* **点击任意卡片查看详细报告**：在汇总报告中点击任意一只基金卡片，**0.01 秒秒级弹出**与单基监控完全相同的全套详细量化报告（含主策略区间标尺滑块、增强因子分位阈值及历史极值发生日期）。
* **常驻一键复制纯文本**：弹窗右上角提供「📋 一键复制文本」按钮，自动按照最新分级策略生成工整的纯文本日报，便于微信交流分享或备忘录归档。

### 4. 💾 一键数据备份与还原
* 支持将全部监控基金一键导出为轻量 JSON 文本；
* 更换手机或平板时，只需粘贴备份文本，即可瞬间无缝恢复全部自选。

## 🛠️ 本地开发与二次构建

如果您希望对代码进行定制修改并自行编译 APK：

### 环境要求
* Node.js (推荐 v18+)
* JDK (推荐 JDK 17 / 21)
* Android SDK (设置 `ANDROID_HOME` 环境变量)

### 构建步骤
```bash
# 1. 克隆代码库
git clone https://github.com/您的用户名/fund_monitor_app_android.git
cd fund_monitor_app_android

# 2. 安装依赖
npm install

# 3. 同步前端资源到 Android 工程
npx cap sync

# 4. 编译生成 Debug APK
cd android
./gradlew assembleDebug
# Windows PowerShell:
# .\gradlew.bat assembleDebug
```
编译产物将生成在 `android/app/build/outputs/apk/debug/app-debug.apk`。
